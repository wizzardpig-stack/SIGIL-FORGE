# SIGIL FORGE

A local-first symbolic design tool for generating, refining, previewing, and exporting custom sigils. The interface treats the workflow as a ritual chamber rather than a generic form-and-preview application.

## Live

https://wizzardpig-stack.github.io/SIGIL-FORGE/

## What it demonstrates

- Client-side generative symbol construction and visualization
- Multiple visual variants, preview modes, color controls, save/export flows, and print output
- Responsive layouts that collapse multi-panel workflows for tablets and phones
- Coarse-pointer mobile performance mode that reduces expensive atmosphere and animation
- Reduced-motion handling for accessibility and performance

## Stack

HTML, CSS, vanilla JavaScript and SVG.

## Development approach

Independent product concept, interaction and visual design, iterative QA, performance tuning, and AI-assisted implementation. The project is intentionally self-contained and runs without a backend.
